## 六、语言润色（2026-11-03）

润色目标：在不改变结构、数据、引注与图表的前提下，使语言更书面、准确、客观、清晰，符合学术文体。主要处理如下。

| 类型 | 润色前（举例） | 润色后 |
| --- | --- | --- |
| 口语化动词 | 把……推到开发者面前；走通研究流程；做成原型；挂接到任务；落库；降级通道；自中断；编码者；不同构 | 使……成为开发者必须面对的问题；完整经历研究流程；实现为原型；归并至任务；数据入库；后备通道；自我中断；编码人员；并不一致 |
| 连接与判断 | 其后果有三；这提示；更重要的是；有对照实验报告；只报告……只报告…… | 由此产生三方面问题；这表明；更为重要的是；一项对照实验报告称；仅报告……仅报告…… |
| 定义句 | 变更溯源是……可追溯其……的证据链 | 变更溯源指……追溯其……的证据链 |
| 因果句 | 之所以不直接采用 PROV：…… | 未直接采用 PROV 的原因在于：…… |
| 设问句 | 关联准确率是多少？SUS 评分如何？处于什么水平？ | 关联准确率达到何种水平？SUS 评分处于何种水平？达到何种水平？ |
| 主语与动词 | 本课题把……；本模块给出……；模型需要满足……；模型的有效性由……检验 | 本课题将……；本模块设计/建立/形成……；模型须满足……；模型的有效性通过……检验 |
| 冗余压缩 | （一）末段逐层罗列 M1—M11 的五个层面（约 200 字） | 压缩为一句并引用表 2-2，避免与表 2-2 重复 |
| 版式 | （三）算法与方法设计的标题落在页底，正文从下页开始 | 在（三）前加 `\clearpage`，避免标题孤行 |

润色后实测 **8708 汉字、18 页**（较润色前 +223 字，主要来自补足主语、连接词与完整句成分）；编译 0 error / 0 Missing character / 0 未定义引用 / 0 Overfull hbox；引注首现顺序仍为 [1]—[44] 单调，图表编号与 3 图 3 表未变；`tex2md.py --check` 两项 `[OK]`。润色以准确与书面为先，未为压缩字数删减论证；若学院硬卡 7000 字，仍按第五节顺序压缩。

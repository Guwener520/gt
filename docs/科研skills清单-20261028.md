## 三、质量与风险提示

1. **安装量不是唯一标准**：>10K 可视为经过大规模使用；1–3K 的小众技能方向往往更对口（如 DeepMind 的 arXiv 检索只有 3.4K），但**装前务必读 SKILL.md 全文**。
2. **来源信誉分层**：官方/大厂仓（`google-deepmind`、`bytedance`、`huggingface`、`langchain-ai`、`karpathy`）优先；个人仓看 star 与最近提交时间。
3. **安全审计要看**：skills.sh 每个技能页有 Gen Agent Trust Hub / Socket / Snyk 三色审计。实测 `nature-reader`、`nature-ref-verifier`、`literature-search-arxiv`、`k-dense-ai@literature-review`、`systematic-literature-review` 的 **Snyk 为 Warn**（其余两项 Pass），装前应点开审计详情确认告警原因。
4. **能力边界**：检索类技能依赖外部 API / MCP（arXiv、OpenAlex、PubMed、Semantic Scholar），国内网络通常要配代理；这类技能**不会**自动解决数据库权限（Web of Science、CNKI 需机构账号）。
5. **幻觉风险仍在**：综述类技能能保证「格式一致的引用」，不保证「引用真实存在」。任何 LLM 生成的文献条目都要过一遍 `nature-ref-verifier` 或 Crossref 核验——这正是本课题 §5.2 的硬约束。
6. **生态兼容**：技能是通用 `SKILL.md` 格式，Claude Code / Cursor / Codex / DSH 都能读；本机技能目录为 `C:\Users\32511\.agents\skills`。

### 3.1 【严重】L293 `[36]`：正文断言与所引文档相反

**正文原句**（L293）：

> 采集侧接口形态差异显著：Claude Code 提供钩子与 stream-json，**其本地 JSONL 被声明为内部格式、随版本变化**，故只作降级通道[36]；

**核查**：抓取 `https://code.claude.com/docs/en/sessions` 全文，原文为

> "**Where transcripts are stored** — By default, Claude Code stores transcripts as JSONL at `~/.claude/projects/<project>/<session-id>.jsonl`"
> "`claude --resume <transcript-path>` — Resumes the session stored in the `.jsonl` transcript file at that absolute path"

并在页面导航中列为 "Export and locate session data"。在 `sessions`、`data-usage`、`security` 三页中检索 `internal format` / `internal use` / `not stable` / `may change` / `subject to change` / `undocumented`，**均无命中**。

**结论**：文档不但没有"声明为内部格式、随版本变化"，反而把 `.jsonl` 作为**官方支持、可导出、可凭绝对路径恢复**的会话数据载体。正文用该断言支撑"只作降级通道"的设计取舍，属**论据与文献相悖**。另：所引 `overview` 页本身不含 `stream-json`/`jsonl` 字样（这两项在 `cli-reference`、`hooks`、`sessions` 页）。

**修改建议**：改为——"Claude Code 提供钩子与 `--output-format stream-json`，其会话记录以 JSONL 存于 `~/.claude/projects/<project>/<session-id>.jsonl`，文档给出存储位置与恢复方式，但未提供格式版本化契约[36]（另引 cli-reference / sessions 页）"；据此把"内部格式"改为"缺少 schema 与兼容性承诺"。

### 3.2 【一般】L66 `[13]`：55.8% 未限定任务与样本

**正文原句**（L66）：

> 使用代价并未随能力提升而消失：有对照实验报告 Copilot 使任务完成速度提升约 55.8%[13]……

**核查**：arXiv 2302.06590 摘要原文——

> "**Recruited software developers were asked to implement an HTTP server in JavaScript as quickly as possible.** The treatment group, with access to the AI pair programmer, completed the task 55.8% faster than the control group."

**结论**：数字**准确**，但该效应来自**单一任务（用 JavaScript 实现一个 HTTP 服务器）**的实验室对照实验，不能外推为一般生产率结论。正文虽写了"有对照实验报告"，但未限定任务与样本，读者易读成通用结论。

**修改建议**：改为"有对照实验在**单一 JavaScript HTTP 服务器实现任务**上报告 Copilot 使完成速度提升约 55.8%[13]"，或补"（任务与样本均受限，不可外推）"。

# 开题报告 v8 修订说明（2026-11-08）

本次修订只处理「一、2 文献综述」：把整块篇幅压到**三页以内**，并按作者要求“直接去掉某些方面、有挑选有侧重”，不以缩写或短句硬压，而是减少综述对象。

## 一、修订依据

作者对 v7 稿的反馈：

1. 文献综述整块篇幅应在**三页之内**；
2. 缩减篇幅时可以精简内容，但**不要使用大量简写缩写**；
3. 应**直接去掉对某些方面的综述**，不必事无巨细，要有挑选有侧重。

v7 稿的综述为五条脉络（智能体评价、变更分析、任务上下文与恢复、过程溯源、工程工具），约 3,005 字、跨第 3—7 页，虽已把文献从 44 条减到 28 条，但仍属“每条脉络都想覆盖”的写法；表 1-1 又占去一页的一部分。v8 因此不再做“逐条压缩”，而是**删掉整条次要脉络与次要例证**，把综述收束为三条与本题直接相关的线索。

## 二、做法

### 2.1 由五条脉络改为三条

| v7 脉络 | v8 处理 |

## 二、逐条（著录 · 提纲 · 原文）

### [1] SWE-bench: can language models resolve real-world GitHub issues?

- **著录**：JIMENEZ C E, YANG J, WETTIG A, et al. SWE-bench: can language models resolve real-world GitHub issues?[C]//Proceedings of the 12th International Conference on Learning Representations. 2024. arXiv: 2310.06770.
- **提纲**：问题——函数级单轮基准无法评价真实仓库级修复；做法——从 12 个 Python 仓库的 issue＋PR 构造 2,294 个任务，以测试由失败转通过判定，测试补丁单独提供；结论——最强模型 Claude 2 仅解决 1.96%，解题常需跨函数、跨文件协同。
- **原文**：`01-Jimenez2024-SWE-bench.pdf`（52 页，ICLR 2024 会议版）。

### [2] SWE-agent: agent-computer interfaces enable automated software engineering

- **著录**：YANG J, JIMENEZ C E, WETTIG A, et al. SWE-agent: agent-computer interfaces enable automated software engineering[C]//Advances in Neural Information Processing Systems 37. 2024. arXiv: 2405.15793.
- **提纲**：把语言模型当作「新的终端用户」，为其设计 ACI（搜索上限、查看窗口、`edit` 命令、linter 拒绝错误落地、旧观察压成一行）；SWE-bench 12.5%、Lite 18.0%、HumanEvalFix 87.7%。
- **原文**：`02-Yang2024-SWE-agent.pdf`（118 页含附录，arXiv v3）。
- **提示**：arXiv 页未标会议，NeurIPS 37 需在 proceedings 页复核；正文「1.31%→18.0%」是 Lite 口径，勿与 12.5% 混用。

### [3] OpenHands: an open platform for AI software developers as generalist agents

- **著录**：WANG X, LI B, SONG Y, et al. OpenHands: an open platform for AI software developers as generalist agents[C]//Proceedings of the 13th International Conference on Learning Representations. 2025. arXiv: 2407.16741.
- **提纲**：平台＝智能体实现＋Docker 沙箱＋多智能体委派＋基准集成（MIT）；状态即事件流（动作、观察、用户消息、成本）；15 个基准评测。
- **原文**：`03-Wang2025-OpenHands.pdf`（38 页，ICLR 2025 会议版）。

### [4] 检索增强生成在软件工程中的应用综述

- **著录**：张犬俊, 谢杨, 房春荣, 等. 检索增强生成在软件工程中的应用综述[J]. 软件学报, 2026, 37(3): 1316-1339. DOI: 10.13328/j.cnki.jos.007567.
- **提纲**：2021—2024 年 108 篇；RAG 架构（检索器／生成器／集成方式）；下游任务（代码生成、测试生成、程序修复）；三阶段挑战（知识库构建、检索、生成）。
- **原文**：`04-Zhang2026-RAG-survey.pdf`（24 页，期刊正式版，首页印卷期页与 DOI）。
- **提示**：作者为张犬俊、谢杨、房春荣、虞圣呈、赵源、陈振宇；摘要只列代码生成/测试生成/程序修复，勿扩写「需求、维护」。

### [5] 基于大语言模型的故障复现测试用例生成方法

- **著录**：汪莹, 字千成, 彭鑫, 等. 基于大语言模型的故障复现测试用例生成方法[J]. 软件学报, 2026, 37(4): 1690-1714. DOI: 10.13328/j.cnki.jos.007474.
- **提纲**：SWE-bench Lite 上近 90% 的 issue 未附复现测试，现有技术依赖错误栈而 issue 常无；方法——检索报错根函数、import、测试样本后构建 prompt 生成；对比＋消融实验。
- **原文**：`05-Wang2026-Failure-reproducing-tests.pdf`（25 页，期刊正式版）。
- **提示**：对象是 GitHub issue 而非智能体会话，正文不宜写成「智能体测试研究」。

### [6] Reading between the lines: modeling user behavior and costs in AI-assisted programming

- **著录**：MOZANNAR H, BANSAL G, FOURNEY A, et al. Reading between the lines: modeling user behavior and costs in AI-assisted programming[C]//Proceedings of the CHI Conference on Human Factors in Computing Systems. 2024: 1-16. DOI: 10.1145/3613904.3641936.
- **提纲**：研究 Copilot 使用行为；提出 CUPS 活动分类法；21 名程序员完成任务并回溯标注；揭示交互低效与时间成本。
- **原文**：`06-Mozannar2024-Reading-between-lines.pdf`（41 页，arXiv v5 含附录；正式版 1–16 页）。

### [7] Do users write more insecure code with AI assistants?

- **著录**：PERRY N, SRIVASTAVA M, KUMAR D, et al. Do users write more insecure code with AI assistants?[C]//Proceedings of the 2023 ACM SIGSAC Conference on Computer and Communications Security. 2023: 2785-2799. DOI: 10.1145/3576915.3623157.
- **提纲**：用户实验比较有无助手完成安全任务；有助手者代码安全性显著更低，且更自信；公开实验装置。
- **原文**：`07-Perry2023-Insecure-code.pdf`（16 页，arXiv 预印本）。

### [8] When do changes induce fixes?

- **著录**：ŚLIWERSKI J, ZIMMERMANN T, ZELLER A. When do changes induce fixes?[C]//Proceedings of the 2005 International Workshop on Mining Software Repositories. 2005: 1-5. DOI: 10.1145/1083142.1083147.
- **提纲**：把 CVS 与 Bugzilla 关联，以修复提交回溯「引入缺陷的变更」（SZZ 源头）；在 Mozilla/Eclipse 上，这类变更在规模与提交星期上呈可辨模式。
- **原文**：`08-Sliwerski2005-When-changes-induce-fixes.pdf`（5 页，MSR 2005 版）。
- **提示**：原文标题作 “When Do Changes Induce Fixes? (On Fridays.)”，与 ACM 短题不同但为同一篇；勿把 3.82／约 3 倍等数字写成该文结论（出自 Kagdi 综述转述）。

- **提纲**：MSR 综述；四维分类（what/why/how/quality）；多数工作以文件/行号为表示单位、以提交与缺陷库为信息源；提出开放问题。

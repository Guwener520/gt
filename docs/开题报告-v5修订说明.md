## 一、修订依据

1. 二不再采用 RQ1—RQ5 的方式行文，改为成段论述；研究边界、创新点、预期成果可以不写。

### 2．初步实施方案

原五模块（理论研究 / 数据模型 / 算法方法 / 原型功能 / 评估验证）改为四模块：

| 模块 | 回答的问题 | 主要内容 |
| --- | --- | --- |
| （一）概念框架与信息模型 | 表示什么 | 三个核心概念；以任务为根的有向异构图（八实体、六类关系）；统一事件结构与基本约束；与 PROV-O 的对应 |
| （二）上下文采集、关联与任务边界 | 如何获得并建立联系 | 会话/工具调用/Git/测试接入；编辑动作归一化为变更块；时间邻近、显式引用、位置映射三类关联线索；空闲时长、显式指令、目标切换、提交动作四类边界特征 |
| （三）变更溯源与任务续接 | 如何查询与使用 | 变更卡片；代码↔原因双向查询；任务快照（已完成/未完成/待验证）；三个视图；证据绑定的大模型摘要与弃答 |

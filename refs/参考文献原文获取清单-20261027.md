## 三、Zotero 中挂载 PDF 的操作（拖拽法）

1. 打开 Zotero，进入集合「任务书参考文献-v1」。
2. 资源管理器中打开 `D:\DSHCode\graduationThesis\refs\pdfs`。
3. **把 PDF 直接拖到对应的条目上**（拖到条目行，不是拖到中间的空白区），松开后 Zotero 会提示「将文件作为附件添加 / 存储副本」——选「存储副本」即可。
4. 文件名前缀（如 `AE38NF87`）就是条目 Key：在 Zotero 中选中条目后按 `Ctrl+Shift+K`？不需要——直接看第一节表格的对应关系即可。
   也可以在 Zotero 条目上右键 →「显示文件位置」确认挂载是否成功。

> 若一次拖多个：Zotero 会把它们都挂到当前选中条目上，**务必一个一个拖**，避免挂错。

## 四、复现方式

抓取脚本在 `refs/tools/`（Python 3，仅标准库，无第三方依赖）：

| 脚本 | 作用 |
| --- | --- |
| `probe.py` | 探测 URL 是否为真 PDF（Content-Type + `%PDF` 魔数） |
| `resolve.py` | Semantic Scholar + Unpaywall 按 DOI 查 OA 位置 |
| `resolve2.py` | Crossref + Fatcat + OpenAlex 兜底查 OA 位置 |
| `download.py` | 批量下载并校验（清单即第一节） |
| `round2.py` / `fix.py` | 断点重试、MetaGPT 流式重下、HAL/Springer 处理、完整性检查 |
| `jos.py` | 软件学报带 Cookie 会话尝试（记录人机校验拦截证据） |
| `grep_page.py` / `find_on_page.py` | 在索引页/作者主页里定位 PDF 链接（用于 PVLDB、作者主页） |
| `verify_pdf.py` | 解压 PDF 内容流做文本级校验，确认每份文件确为目标论文 |

**环境备注**：本机 PowerShell 5.1 与 curl 的 schannel TLS 栈握手失败（`SEC_E_NO_CREDENTIALS`），
HTTPS 下载统一改走 Python（OpenSSL 3.5.8）；部分站点证书链不完整，脚本使用不校验证书的 SSL 上下文。
`web_search` 工具因缺少 API key 不可用，Bing/DDG 的 HTML 结果被地域重定向污染，故改用 Crossref/Unpaywall/OpenAlex/Fatcat 等结构化 API 定位。
